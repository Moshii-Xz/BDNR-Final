1. Instalar docker compose. En sistemas operativos Linux como Ubuntu lo podemos hacer con el comando:

```
sudo apt install docker-compose-plugin -y
```

2. Creamos el archivo "docker-compose.yml" y agregar lo siguiente:

```yaml
version: '3.8'

services:
  dynamodb_local:
    image: amazon/dynamodb-local:latest
    container_name: dynamodblocal
    user: root
    restart: always
    ports:
      - "3000:8000"
    volumes:
      - dynamodb_local_volume:/home/dynamodblocal/data
    command: "-jar DynamoDBLocal.jar -sharedDb -dbPath ./data"
    networks:
      - aws_network

  aws_cli:
    image: amazon/aws-cli:latest
    container_name: awscli
    stdin_open: true
    tty: true
    entrypoint: /bin/bash
    networks:
      - aws_network
    environment:
      - AWS_ACCESS_KEY_ID=local
      - AWS_SECRET_ACCESS_KEY=local
      - AWS_DEFAULT_REGION=us-east-1

networks:
  aws_network:
    driver: bridge

volumes:
  dynamodb_local_volume:
```

3. Nos ubicamos en el mismo directorio donde agregamos el archivo creado en el punto anterior.

4. Creamos y arrancamos los contenedores definidos en el archivo usando el comando:

```
docker compose up -d
```

5. Entramos de forma interactiva al contenedor "awscli" con el comando:

```
docker exec -it awscli /bin/bash
```

6. Probamos que podamos consumir los servicios del contenedor "dynamodblocal" desde el contenedor "awscli":

```
aws dynamodb list-tables --endpoint-url http://dynamodblocal:8000
```

Debe retornar algo como:

```json
{
    "TableNames": []
}
```
